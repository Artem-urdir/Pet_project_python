# Pet_project_python
Задание: Собрать датасет, проанализировать рынок конкретной отрасли, посчитать метрику и сделать вывод. Для этого предоставлен реестр всех предпринимателей из ФНС, требуется его подготовить к работе(вас интересуют юридические лица, среднее и малые предприятия, в видах деятельности указывайте 41.20 Строительство жилых и нежилых зданий). Определите насколько перспективна отрасль строительства с помощью подсчёта EBITA всех компаний по годам. Но в данной таблице не будут выложены данные, нужные для подсчёта этой метрики, поэтому вам потребуется с этой (https://bo.nalog.gov.ru/) странички спарсить все нужные данные. Также вам предстоит построить графики (x=процент роста чистой прибыли компании относительно N-летней давности, у-Количество компаний с таким процентном) х-целое число, N вы подбирайте на своё усмотрение. Также требуется написать вывод после увиденных графиков. Затем ознакомьтесь с geopandas. И нанесите топ500 компаний по выручке на карту по месту регистрации.
